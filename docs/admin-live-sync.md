# 어드민 자동 동기화

로그인한 어드민은 보이는 탭에서 15초마다 GitHub의 페이지 목록과 파일 버전을 확인합니다. 대화로 수정하고 GitHub에 반영한 HTML, 이미지 연결, 블록 구성은 편집 중인 내용이나 초안이 없으면 자동 반영됩니다. 탭으로 돌아왔을 때도 확인하며, 화면의 '지금 동기화' 버튼으로 바로 확인할 수 있습니다.

공개 사이트의 css/style.css도 확인해 어드민의 실제 화면 미리보기에 적용합니다. CSS는 GitHub Pages 배포가 완료된 후 반영됩니다. 입력 필드나 작성 중인 글은 스타일 갱신으로 초기화되지 않습니다.

미저장 입력이나 저장된 초안이 있는 페이지에 외부 변경이 생기면 초안을 유지하고 충돌 안내를 표시하며 발행을 차단합니다. 최신 원본 보기와 초안 백업으로 비교한 뒤 초안을 정리하세요. 외부에서 내려간 페이지도 초안이 있으면 보존합니다. 동기화 요청 중 입력을 시작하거나 페이지를 이동했을 때는 이전 요청 결과를 적용하지 않습니다.

로그아웃, 숨겨진 탭, 발행 작업이나 대화상자가 열린 동안에는 확인을 중지하거나 연기합니다. 일시적인 연결 실패는 다음 주기에 재시도합니다. 로컬 파일 저장만으로는 반영되지 않으며 GitHub push가 필요합니다. 관리자 프로그램 자체의 새 기능은 해당 버전 배포 후 한 번 새로고침해야 합니다.
