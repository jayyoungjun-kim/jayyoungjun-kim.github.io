# 이미지 운영

관리자 왼쪽의 **이미지 보관함**에서 파일을 업로드하고, 원래 파일명으로 검색하고, 주소를 복사하거나 삭제할 수 있습니다. 보관함 업로드는 GitHub에 즉시 저장되며 Pages 배포 후 공개 주소에서 제공됩니다. 다른 기기에서도 Google 로그인 후 같은 보관함을 사용할 수 있습니다.

페이지의 이미지 편집에는 **파일 선택 · 교체**와 **보관함에서 선택**이 있습니다. 페이지에서 직접 선택한 파일은 초안에 연결되며, 페이지를 발행할 때 이미지도 함께 GitHub에 저장됩니다. 사용 중인 이미지는 연결을 변경하고 페이지를 발행한 뒤 삭제하세요. 저장된 초안에서도 참조 중이면 삭제를 차단합니다. 삭제해도 Git 이력의 파일은 남습니다.

정적 PNG/JPEG/WebP는 브라우저에서 비율을 유지하며 긴 변 최대 2,560px, WebP 품질 88%로 처리합니다. 변환 결과가 더 크면 원본을 유지합니다. GIF/APNG/움직이는 WebP는 애니메이션을 보존하도록 원본을 유지합니다. 입력 최대 40MB, 최종 저장 파일 최대 8MB, 정적 이미지 최대 6,400만 화소입니다. 페이지 발행에서 새 파일의 합계는 24MB까지이며, 이미 저장소에 있는 이미지는 이 합계에 포함하지 않습니다.

이미지는 assets/uploads/에 고유 이름으로 저장합니다. assets/uploads/library.json은 표시용 원래 파일명 목록이며 GitHub의 같은 커밋에 저장됩니다. 새 이미지를 선택하면 새 URL이 생성됩니다.
